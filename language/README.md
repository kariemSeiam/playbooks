# Language — playbooks for a specific notation or language

Not a topic like `playbooks/github/` (one domain, one concern) — a
category. Each subfolder here is the standing law for writing well in one
specific language or notation. `markdown/` is the first because it's the
one in constant use across this vault's own files; add a sibling folder
the same shape (a [README.md](README.md) index + focused topic files) the next time
a different language earns the same treatment.

## Subfolders

- **`markdown/`** — how to write any `.md` file: syntax, voice, document
  type, and the structural difference between writing for a human versus
  writing for an agent's own future reading.
